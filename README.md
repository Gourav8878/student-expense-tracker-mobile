# Student Expense Tracker Mobile App

A mobile application designed to help students track and manage their daily expenses.

## About the Project

Student Expense Tracker is a mobile app developed using React Native and Expo. It aims to make expense tracking easier for students through a mobile-friendly interface.

## Tech Stack

- React Native
- Expo
- TypeScript
- JavaScript

## Features

- Track student expenses
- View and manage expense records

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/Gourav8878/student-expense-tracker-mobile.git
   ```

2. Navigate to the project folder:

   ```bash
   cd student-expense-tracker-mobile
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Expo development server:

   ```bash
   npx expo start
   ```

5. Scan the QR code using Expo Go to run the application on your phone.
